# Security policy

## Supported versions

Only the latest v1 release is supported. [Stability](docs/stability.md) says
what a v1 release will not break.

## Reporting a vulnerability

Report privately through GitHub's "Report a vulnerability" button on the
repository's Security tab. Please do not open a public issue.

Expect an acknowledgement within a few days. Fixes are disclosed once a
release is available, and no later than 90 days after the report.
